墨枢 InkAxis - 交互设计文档

版本：IDD V1.0  |  关联 PRD：V2.1

本文档描述墨枢产品的用户界面与交互细节，功能定义与业务逻辑见《产品需求文档》。

1. 设计原则

  • 沉浸优先：写作是深度工作，UI 应消隐，内容应凸显
  • 渐进披露：高级功能不主动打扰，需要时自然出现
  • 即时反馈：AI 操作流式输出，不出现空白等待
  • 可逆操作：所有 AI 修改可回滚，消除恐惧感

3. 选中即操作

用户选中文字后浮窗出现（延迟 200ms），包含字数统计和操作按钮。按钮项：基础校正、风格重塑 ▸（展开子菜单）、扩写、缩写、转为对话、检查一致性。

┌──────────────────────┐ │ ✨ AI 助手 │ │ 📝 基础校正 │ │ 🎨 风格重塑 ▸ │ │ 📏 扩写 │ │ 📐 缩写 │ │ 💬 转为对话 │ │ 📋 检查一致性 │ └──────────────────────┘

AI 处理结果以侧边批注形式呈现，用户逐条 接受 / 拒绝 / 修改。

4. AI 生成内容标识

采用左侧色条 + 底部小标签方案。AI 生成段落左侧有绿色竖线，底部显示“[AI生成] [接受] [重写] [编辑]”操作栏。

5. 版本快照系统

每次 AI 大改前自动创建快照，用户可手动创建。快照列表显示时间、标题、字数变化。支持 diff 对比视图（左右分栏，高亮差异）。

6. 渐进式用户引导

  • 欢迎页：选择身份（网文作者/短剧编剧/新人），给出对应快速开始路径。
  • 新建作品：输入书名+简介，AI 生成可选世界观设定卡片，点击选用。
  • 空状态：编辑区中心显示占位提示“写下你的故事，或点击续写让AI帮你起头”。
  • 功能发现：写够500字，在选中文字时弹出提示“试试选中文字使用AI助手”；写够3000字，顶部出现“🎬 将此章节改编为剧本”按钮。

三栏布局，原文与剧本高亮联动。心理外化策略可选择后实时预览。

8. 命令面板

快捷键 Cmd/Ctrl + K 呼出，支持模糊搜索命令。分类：续写、润色、剧本、其他。

9. 异常状态 UI

具体处理逻辑见《技术方案文档》，此处仅列交互样式：

  • A级服务不可用：顶部横幅提示，带重试和离线写作按钮。
  • B级结果不可用：原区域显示错误卡片，可重新生成。
  • C级质量低：生成内容下方显示浅黄色提示条。
  • D级部分拦截：被改词高亮为黄底，hover可查看原文。
