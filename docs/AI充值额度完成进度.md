# AI 充值额度完成进度

## 当前状态

- 阶段：v1 骨架实现中。
- 安全默认值：`billing.enforcement-enabled=false`，支付网关未配置前不强制扣费、不伪造支付成功。

## 已完成

- 设计方案确认：用户级预付费人民币余额。
- 套餐确认：¥10、¥30、¥100、¥300。
- 扣费原则确认：调用前冻结、调用后短事务结算，不在数据库事务内调用模型。
- 支付原则确认：支付宝/微信异步通知验签后入账，前端成功页不可信。
- 设计文档：`docs/AI充值额度计费设计文档.md`。
- 功能点清单：`docs/AI充值额度功能点清单.md`。
- 数据库骨架：钱包、流水、充值订单、用量冻结表。
- 后端骨架：套餐目录、BigDecimal 金额计算、钱包服务、充值订单服务、支付策略接口。
- 同步聊天入口：已接入调用前冻结和调用后结算，异常释放冻结。
- 用户 Token 用量页：已增加余额、充值套餐、最近订单、钱包流水入口。
- 日志：已覆盖订单创建、冻结、结算、释放、支付通知未配置等关键路径。

## 进行中

- 后端编译验证：本机默认 Java 8 不满足项目 Java 21；IDEA JBR 为 Java 25，与当前 Lombok/编译链不兼容。
