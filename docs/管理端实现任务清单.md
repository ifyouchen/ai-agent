# 管理端 V1 实现任务清单

版本：V1.0  
日期：2026-06-27  
范围：将现有零散管理员能力升级为独立 Admin Console 管理端

## 1. 执行原则

- 管理端和普通业务端分离：业务端保留对话、创作、知识库、组织协作；管理端负责全局治理。
- V1 只做可落地闭环：Dashboard、用户管理、知识库管理、文档管理、用量成本。
- 复用现有 JWT、`ROLE_ADMIN`、Token 统计、知识库、文档、创作任务数据。
- 不引入新的 UI 框架，不重做当前设计系统。
- 页面和方法避免过长：路由级 Vue 页面建议不超过 300 行，复杂 UI 拆到 `components/admin/`。
- 后端保持 Controller -> Service -> Mapper 分层，统计聚合放 Service，不在 Controller 堆长逻辑。
- 每完成一个模块，必须同步更新 `管理端实现进度记录.md`。

## 2. V1 范围

V1 包含：

- 独立管理端布局和左侧导航。
- `/admin` 重定向到 `/admin/dashboard`。
- Dashboard 总览：成本、错误率、用户、知识库、文档、任务摘要。
- 用户管理：搜索、分页、启用、禁用、设管理员、用户详情。
- 知识库管理：全局知识库分页列表和筛选。
- 文档管理：全局文档分页列表、解析状态筛选、失败原因展示。
- 用量成本：每日趋势、模型消费占比、用户消费排行。
- 管理端任务清单和进度记录文档。

V1 暂不包含：

- 复杂 RBAC 权限矩阵。
- 计费套餐、租户冻结和组织治理工作流。
- 审计日志入库重构。
- 文档解析重试。
- 系统设置写入能力。
- 批量删除、批量禁用等高风险操作。
