# AI 充值额度功能点清单

## 用户侧

- 查看钱包余额：可用余额、冻结余额、累计充值、累计消费。
- 查看充值套餐：¥10、¥30、¥100、¥300。
- 创建充值订单：选择套餐和支付渠道。
- 查看充值订单状态：待支付、已支付、已关闭、已退款。
- 查看钱包流水：充值、冻结、结算、释放、退款、人工调整。
- 余额不足时阻止 LLM 调用，并提示充值。
- Token 用量页展示余额、套餐入口和近期消费数据。

## 后端计费

- 钱包账户自动初始化。
- LLM 调用前原子冻结预估费用。
- LLM 调用后按实际 token 成本结算。
- 调用失败或超时释放冻结金额。
- 防止并发透支。
- 防止重复扣费和重复入账。
- 支持配置 USD/CNY 汇率、成本倍率、单次调用上限、日消费上限。

## 支付

- 支付宝充值订单接口。
- 微信充值订单接口。
- 支付宝异步通知验签和入账。
- 微信 API v3 异步通知验签、解密和入账。
- 主动查单兜底。
- 订单过期关闭。
- 支付对账和异常订单人工处理。

## 管理侧

- 查询用户钱包。
- 查询充值订单。
- 查询钱包流水。
- 查询异常冻结。
- 手工调整余额，必须写审计流水。
- 查看每日充值、消费、余额变化。
